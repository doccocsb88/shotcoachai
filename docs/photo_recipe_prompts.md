# Photo Recipe Prompts Collection

This document contains the prompt engineering data for all 22 Photo Recipes in ShotCoach AI.

## 1. Coastal Blue Day
- **Category**: beach
- **Film Simulation**: Classic Chrome inspired
- **Mood**: Fresh coastal atmosphere.
- **Color Palette**: Clean whites, turquoise water, bright blue sky.
- **Lighting**: Bright natural daylight.
- **Contrast**: Soft-medium contrast.
- **Saturation**: Moderately vibrant but realistic.
- **Grain**: Very fine film grain only if it looks natural.
- **Negative Prompt**: Avoid heavy teal grading, fake tropical colors, HDR skies, or fantasy beach lighting.
